# FocusMode

FocusMode is a productivity tool to help you stay focused by blocking distracting websites and applications during designated focus periods.

> I made this tool for myself because I often found myself distracted by social media and other non-work-related websites and applications. I wanted a simple way to block these distractions during my work hours that didn't require complex configurations and was open source. Yeah I'm aware I could use existing tools but I wanted to build something myself and learn Go along the way.

## Features

- Block distracting websites (modifies hosts file)
- Block distracting applications (modifies system settings by aliasing applications commands)
- Customizable block lists
- Simple command-line interface

## Planned Features

- Schedule focus sessions/days
- Support for Pomodoro Technique
- Cross-platform support (Windows, macOS, Linux)
